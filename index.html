Конфигуратор щитов DEKraft / Systeme Electric — v31

Добавлены пользовательские блоки AutoCAD по вашим именам, блоки корпусов ЩРНМ и монтажных плат по вашему стандарту, а также учтены реальные габариты аппаратов из загруженных PDF по ВА-105, ВА-103, ВА-201, ВН-102, МК-103, ДИФ-103 и УЗДП-103. Вкладка «Разное» позволяет вручную добавлять свои обозначения, референсы, наименования, модули и имя блока для DXF-экспорта. Excel-выгрузка результата сохранена.

Ввод щитов

Отдельная строка на каждый щит. Слева — название щита, справа — коды аппаратов. Примеры: 320, 116, 3.20, 1.16, 12ав316, 3x320, 316 x6, 2хд25. Количество: 10ав310, 6д16, 3b116, 2вн316. Латинская d — характеристика D, русская д — дифавтомат. Новая строка — новая DIN-рейка; аппараты через запятую размещаются на одной рейке.

Массовая вставка из Excel

Скопируйте из Excel сразу два столбца: 1-й столбец — название щита, 2-й столбец — коды/состав аппаратов. Вставьте сюда табличный фрагмент и нажмите импорт. Поддерживаются строки, разделённые табуляцией. Коды вроде 9д16 и 10д20 распознаются как количество + дифавтомат.

Сгенерированные файлы

После нажатия на экспорт здесь появятся ссылки на готовые файлы. Если браузер не начинает скачивание автоматически, нажмите ссылку вручную.

Разное / пользовательские позиции

Аналог вашей вкладки «Разное» из Excel. Здесь можно добавлять свои обозначения, референсы, наименования, число модулей и имя блока AutoCAD. Если код совпадает с базовым кодом, пользовательская запись будет иметь приоритет.
